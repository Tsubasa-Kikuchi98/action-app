# 実際のアクション映画予告と比べて足りないもの（ギャップ分析）

作成: 2026-08-29。対象: `out/demo3/trailer.mp4`（Phase 2 版）と `trailer_v2_preview.mp4`（Phase 3 試作）。
凡例: 💰 = API 課金が必要（Veo 再生成・画像再生成）／ 🆓 = ffmpeg・プロンプト・TTS（≒$0）で対応可／ ⛔ = Phase 3 スコープ外（BGM・効果音）

## 0. 一言で
本物の予告は「**音が 7 割**」。映像は 4 秒カットの AI 動画でも成立するが、音が「ナレーション 1 本＋ほぼ無音」では臨場感が出ない。次に大きいのは「**カットの速さと種類の変化**」。

## 1. 音（最大のギャップ）

| # | 本物にあるもの | 現状 | 対応 |
|---|---|---|---|
| 1-1 | **登場人物のセリフ**（1〜3 本。「行くぞ」「まだ終わってない」等の短い決め台詞。画面の人物が喋る、または別カットに声だけ乗る） | 一切なし。Veo に「no dialogue」と指示している | 🆓 台本に `dialogue` を追加し TTS（ナレと別の声）で生成、カット上に乗せる（口パク同期なし＝「声だけ乗せ」型）／💰 Veo に引用符でセリフを渡して口パク付きで生成し直す |
| 1-2 | **シーンの生活音・現場音**（キーボード、足音、警報、雨、ガラス、サーバーファン、息遣い） | Veo が生成した音はあるが −12dB＋ダッキングでほぼ無音。試作版は完全に落としている | 🆓 Veo 音声を 0.25 → 0.8〜1.0 に上げ、ナレ中だけ −6dB 程度に軽くダッキング。試作版のカットランプにも環境音レーンを通す |
| 1-3 | **編集点のヒット音・ウーッシュ・ブラーム**（カットのたびに「ドン」「シュッ」） | なし | ⛔ 効果音はスコープ外（Phase 4 で ElevenLabs SFX or フリー素材）。🆓 代替として Veo 音声のトランジェントをカット頭に合わせる（トリム位置の工夫） |
| 1-4 | **音楽の起伏**（静かなピアノ → ライザー → ドロップ → 無音 → タイトルでブラーム） | 一定の合成ドローン。起伏なし | ⛔ BGM はスコープ外。🆓 「タイトル前の無音」だけは実装できる（stopdown） |
| 1-5 | **無音の使い方**（ドロップ直前・タイトル直前の 0.5 秒の完全な静寂） | なし（試作版で黒 0.5 秒は入れたが音は継続） | 🆓 映像の黒と同時に全レーンを無音に |
| 1-6 | **ナレーションの緩急**（囁き → 加速 → 張り上げ → 最後は一言） | 全シーン同一テンション、speed 1.15 で「重厚」と矛盾 | 🆓 speed 1.0、シーンタイプ別 instructions、公式ラベル形式 |
| 1-7 | **ナレの音作り**（胸で響く低域、コンプで前に出る、薄いリバーブ） | TTS 素のまま | 🆓 EQ＋コンプ＋短エコー＋リミッタ（検証済みチェーン） |
| 1-8 | **音の空間**（セリフは部屋の響き、ナレは無響で前に、環境音は後ろに） | すべて同一平面 | 🆓 セリフに `aecho`（小部屋）、環境音に軽い `lowpass`、ナレは無処理で前に |
| 1-9 | **ラウドネスの迫力**（劇場予告は −14 LUFS よりも密度が高く、ピークが −1dB に張り付く） | −14 LUFS、ダイナミクス広め | 🆓 `loudnorm` の I=−14 は維持しつつ、最終段に `alimiter` で密度を上げる（配信基準は守る） |

## 2. 編集・リズム

| # | 本物にあるもの | 現状 | 対応 |
|---|---|---|---|
| 2-1 | **カットの加速**（前半 3〜4 秒/カット → 終盤 0.5〜1 秒/カット、最後は 10 カット/5 秒のモンタージュ） | 5 カット均等（4〜6 秒） | 🆓 カットランプ（試作済み）。既存クリップを split/trim して 10〜14 カットに |
| 2-2 | **ショットサイズの変化**（ワイド → 寄り → 手元インサート → 顔） | 全カットがミディアム〜ワイドで同じ距離感 | 🆓 既存クリップから `crop`＋`scale` で疑似的な寄り（インサート）を切り出す／💰 起点画像の image_prompt にショットサイズを指定して再生成 |
| 2-3 | **音楽のビートにカットを同期** | 同期なし | ⛔ BGM がスコープ外のため保留。🆓 ナレの句切れにカットを合わせることは可能 |
| 2-4 | **スマッシュカット・ハードカット主体、フェードは要所のみ** | 全カットが xfade（フェード／白フェード） | 🆓 ハードカット主体に。白フラッシュは加速点 1 箇所 |
| 2-5 | **速度ランプ**（スローモーション → 通常速度、瞬間の引き伸ばし） | なし | 🆓 `setpts` で montage の 1 カットをスローに |
| 2-6 | **フラッシュフレーム・シェイク**（衝撃の瞬間に白 2 フレーム、手ブレ） | なし | 🆓 検証済みフィルタで追加 |
| 2-7 | **冒頭の掴み**（最初の 3 秒に強いビジュアルか音） | 5 秒の静止ワイド | 🆓 s1 を 3 秒に詰める／💰 起点画像を「動きのある構図」で再生成 |
| 2-8 | **中間タイトルカード**（「この夏」「全てが、変わる」「誰も、逃げられない」を黒背景で 1 秒ずつ挿入） | タイトルカードは最後の 1 枚のみ | 🆓 台本に `interstitial` テロップを 2 枚追加し、黒背景カードとしてカット間に挿入 |
| 2-9 | **エンドカード情報**（公開日「2026 冬、公開」「COMING SOON」、キャスト名、配給ロゴ） | 「COMING SOON」のみ | 🆓 台本に `release_line`（例:「この冬、社内公開」）とキャスト行（登場人物の役職名）を追加 |
| 2-10 | **冒頭のスタジオロゴ／レーティング風カード** | なし | 🆓 「○○部 PRESENTS」等の白文字 1.5 秒を先頭に（ネタとしても効く） |

## 3. 映像の内容

| # | 本物にあるもの | 現状 | 対応 |
|---|---|---|---|
| 3-1 | **アクションそのもの**（走る、殴る、爆発、車、落下。物理的な動き） | 座ってモニターを見る、立って外を見る。全カットが静的 | 💰 台本の motion_beat に「立ち上がる／走る／机を叩く／ドアを蹴る」等の力の動詞を強制して Veo 再生成。🆓 台本側の仕組み（motion_beat / camera_beat）は先に実装しておく |
| 3-2 | **カメラの動き**（ドリー、クレーン、ハンドヘルド、ウィップパン） | ほぼ固定か微動 | 💰 motion-first プロンプトで再生成。🆓 既存クリップに push-in / 手ブレを後付け（部分的） |
| 3-3 | **人物の一貫性**（同じ主人公が全カットに出る） | s2 の主人公と s4 の人物が別人 | 💰 Veo Fast ＋ referenceImages（Lite 非対応）。🆓 正面顔のカットを減らし、シルエット・後ろ姿・手元中心に組む（演出で逃げる） |
| 3-4 | **舞台の広がり**（屋外、街、車内、屋上。ロケーションが 3〜5 箇所） | 全部オフィス | 💰 image_prompt で舞台を分散／🆓 台本プロンプトに「舞台は最低 3 箇所」を追加（次回生成から効く） |
| 3-5 | **敵・障害の可視化**（対立する相手、迫るタイマー、赤い警告） | 抽象的（「見えない原因」） | 🆓 台本プロンプトで「脅威を具体的な視覚要素で 1 つ描く」を強制（次回生成から） |
| 3-6 | **画面内の文字要素**（モニターの警告文、時計、カウントダウン） | なし（テロップのみ） | 🆓 ASS で「02:00 AM」「ALERT」等の小さな画面内テロップを演出として重ねる（合成なので破綻しない） |
